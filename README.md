# AI-Powered Aviation MRO Audit Findings Trend Analysis

## Project Overview

This project develops an AI-powered Audit Findings Trend Analysis System
for an Aviation Maintenance, Repair and Overhaul (MRO) organisation.

The application will:

- Import audit findings from Excel
- Perform automated data quality checks
- Analyse audit trends
- Generate management dashboards
- Detect recurring root causes
- Analyse human factors
- Produce executive reports
- Provide AI-assisted recommendations

## Technology Stack

- Python
- Pandas
- DuckDB (later phase)
- Streamlit
- Plotly
- Matplotlib
- Scikit-learn
- python-docx
